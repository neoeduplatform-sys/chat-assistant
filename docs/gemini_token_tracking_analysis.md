# Gemini Token Tracking and Cost Analysis

This document provides a comprehensive analysis of how we can extract, track, and calculate token usage and costs for each client request when communicating with the Google Gemini API using LlamaIndex.

## 1. Availability of Token Usage Data in the API

Yes, token usage information is fully available when using LlamaIndex's `GoogleGenAI` class (which wraps the Gemini API).

### How LlamaIndex Exposes Token Counts
For each LLM response (`ChatResponse` or `CompletionResponse`), the `llama-index-llms-google-genai` integration automatically maps the Gemini API's `usage_metadata` into two places on the returned object:

1. **`response.additional_kwargs`**:
   LlamaIndex maps the usage statistics into standard dictionary keys:
   - `prompt_tokens`: Number of input tokens in the prompt.
   - `completion_tokens`: Number of output tokens generated by Gemini.
   - `total_tokens`: Total tokens (`prompt_tokens` + `completion_tokens`).

2. **`response.raw`**:
   The raw response object returned from the Google GenAI SDK is preserved here. It contains a `usage_metadata` object with fields:
   - `prompt_token_count`
   - `candidates_token_count`
   - `total_token_count`

## 2. Dynamic Token Tracking per Request

Since the backend is built on **FastAPI** and processes multiple requests concurrently, we must track token usage thread-safely and avoid race conditions.

Within a single request cycle, there are two distinct LLM calls:
1. **RAG Response Synthesis**: Generating the main response via `course_query_engine.synthesize(...)`.
2. **Rolling Memory Summary** (Optional): Updating the conversation summary via `summarize_conversation(...)` if the summary budget triggers a refresh.

### The Callback & ContextVars Solution
To capture tokens from **both** calls dynamically and associate them with the current HTTP request, we can use a custom LlamaIndex `CallbackHandler` combined with Python's built-in `contextvars` module.

```python
import contextvars
import logging
from typing import Any, Dict, Optional
from llama_index.core.callbacks import BaseCallbackHandler, CBEventType, EventPayload

logger = logging.getLogger(__name__)

# Context-local dictionary to track tokens during an active HTTP request
token_tracker_context = contextvars.ContextVar("token_tracker_context", default=None)

class TokenTrackerCallbackHandler(BaseCallbackHandler):
    """Custom LlamaIndex Callback Handler to track LLM token counts thread-safely."""
    
    def __init__(self) -> None:
        super().__init__(event_starts_to_ignore=[], event_ends_to_ignore=[])

    def on_event_start(self, event_type, payload=None, event_id="", parent_id="", **kwargs):
        return event_id

    def on_event_end(self, event_type, payload=None, event_id="", **kwargs):
        if event_type == CBEventType.LLM and payload:
            response = payload.get(EventPayload.RESPONSE)
            if response:
                additional_kwargs = getattr(response, "additional_kwargs", {}) or {}
                p_tokens = additional_kwargs.get("prompt_tokens")
                c_tokens = additional_kwargs.get("completion_tokens")
                
                # Fallback to raw response if additional_kwargs keys are missing
                raw_response = getattr(response, "raw", None)
                if raw_response and (p_tokens is None or c_tokens is None):
                    usage_metadata = getattr(raw_response, "usage_metadata", None)
                    if usage_metadata:
                        p_tokens = getattr(usage_metadata, "prompt_token_count", p_tokens)
                        c_tokens = getattr(usage_metadata, "candidates_token_count", c_tokens)
                
                # Update context-local tracker if active
                tracker = token_tracker_context.get()
                if tracker is not None:
                    if p_tokens is not None:
                        tracker["prompt_tokens"] += int(p_tokens)
                    if c_tokens is not None:
                        tracker["completion_tokens"] += int(c_tokens)
                    tracker["total_tokens"] = tracker["prompt_tokens"] + tracker["completion_tokens"]
```

## 3. Cost Calculation per Request

The cost can be computed dynamically at the end of the request handler by matching the model name against current pricing sheets.

### Gemini API Pricing Model (USD per Million Tokens)

| Model Name | Input Rate (per 1M tokens) | Output Rate (per 1M tokens) |
| :--- | :--- | :--- |
| **Gemini 1.5 Pro** | $1.25 | $5.00 |
| **Gemini 2.5 Flash** | $0.30 | $2.50 |
| **Gemini 1.5 Flash** | $0.075 | $0.30 |

### Cost Calculation Utility
```python
def calculate_gemini_cost(model_name: str, prompt_tokens: int, completion_tokens: int) -> float:
    """Calculate the request cost in USD based on model pricing."""
    model = (model_name or "").lower()
    
    # Default rates (Gemini 1.5 Pro)
    input_rate = 1.25 / 1_000_000
    output_rate = 5.00 / 1_000_000
    
    if "gemini-2.5-flash" in model:
        input_rate = 0.30 / 1_000_000
        output_rate = 2.50 / 1_000_000
    elif "gemini-1.5-flash" in model:
        input_rate = 0.075 / 1_000_000
        output_rate = 0.30 / 1_000_000
    elif "gemini-1.5-pro" in model:
        input_rate = 1.25 / 1_000_000
        output_rate = 5.00 / 1_000_000
        
    return (prompt_tokens * input_rate) + (completion_tokens * output_rate)
```

## 4. Implementation Steps (Planned Modifications)

When approved, the tracking mechanism will be integrated across the codebase as follows:

### Step 1: Update API Response Models (`app/models.py`)
Introduce a `TokenUsageInfo` model and append it as an optional field in `ChatResponse`:
```python
class TokenUsageInfo(BaseModel):
    prompt_tokens: int = Field(..., description="Number of input tokens")
    completion_tokens: int = Field(..., description="Number of output tokens")
    total_tokens: int = Field(..., description="Total tokens used")
    cost: float = Field(..., description="Cost of the request in USD")

class ChatResponse(BaseModel):
    # Existing fields...
    answer: str
    sources: Optional[List[str]] = None
    course_id: str
    user_id: Optional[str] = None
    # New tracking metadata
    usage: Optional[TokenUsageInfo] = Field(None, description="Token usage and cost metrics")
```

### Step 2: Register global callback handler (`app/main.py`)
In `initialize_query_engine()` during LlamaIndex initialization:
```python
        # Register the token tracking handler globally
        from llama_index.core.callbacks import CallbackManager
        Settings.callback_manager = CallbackManager([TokenTrackerCallbackHandler()])
```

### Step 3: Implement Context Management in the Chat Endpoint (`app/main.py`)
Wrap the `/api/chat` processing in a `try...finally` context to set, update, and read the `token_tracker_context`:
```python
@app.post("/api/chat", response_model=ChatResponse)
async def chat_endpoint(request: ChatRequest, current_user = Depends(get_current_user)):
    ...
    # 1. Initialize tracker in the current context
    token = token_tracker_context.set({
        "prompt_tokens": 0,
        "completion_tokens": 0,
        "total_tokens": 0
    })
    
    try:
        # Proceed with existing query engine execution & summarization
        ...
        
        # 2. Extract accumulated token usage
        usage_data = token_tracker_context.get()
        model_name = getattr(Settings.llm, "model", None) or os.getenv("GEMINI_MODEL", "models/gemini-1.5-pro-latest")
        
        cost = calculate_gemini_cost(model_name, usage_data["prompt_tokens"], usage_data["completion_tokens"])
        
        # 3. Log results to system log
        logger.info(
            "📊 Request Token Usage | model=%s | prompt=%d | completion=%d | total=%d | cost=$%.6f",
            model_name, usage_data["prompt_tokens"], usage_data["completion_tokens"], usage_data["total_tokens"], cost
        )
        
        # 4. Return enriched response
        return ChatResponse(
            answer=answer,
            sources=sources,
            course_id=request.course_id,
            user_id=request.user_id,
            usage=TokenUsageInfo(
                prompt_tokens=usage_data["prompt_tokens"],
                completion_tokens=usage_data["completion_tokens"],
                total_tokens=usage_data["total_tokens"],
                cost=cost
            )
        )
    finally:
        # 5. Clean up the ContextVar to prevent memory leaks
        token_tracker_context.reset(token)
```
