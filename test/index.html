🚀 Sitio Dummy de Prueba

Ejemplo de integración del chatbot en modo columna

Bienvenido al Sitio de Prueba

Este es un sitio dummy para demostrar la integración del chatbot en modo columna. El chat está integrado en una columna lateral que se puede expandir y contraer.

💡 Características del Chat

El chatbot está configurado en modo columna. Haz clic en el botón flotante en la esquina inferior derecha para abrir/cerrar el chat.

Contenido de Ejemplo

Este es contenido de ejemplo para llenar el espacio. Puedes agregar cualquier contenido aquí y el chat se adaptará automáticamente.

Características

  • Modo Columna: El chat se integra como una columna lateral
  • Altura Adaptable: El chat ocupa el 100% de la altura del contenedor
  • Ancho Configurable: Actualmente configurado al 40% del ancho
  • Responsive: Se adapta a diferentes tamaños de pantalla
  • Sin Dependencias: Todo está incluido en el widget

Instrucciones

Para probar el chat:

  1. Haz clic en el botón flotante en la esquina inferior derecha
  2. La columna del chat se expandirá mostrando el 40% del ancho
  3. Escribe una pregunta en el campo de texto
  4. Presiona Enter o haz clic en el botón de enviar
  5. El chat se conectará a la API en http://localhost:8080/api/chat

🔧 Configuración

La configuración del chat está en el <head> de este archivo. Puedes modificar colores, textos y el ancho de la columna desde ahí.
